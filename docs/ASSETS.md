# Asset credits

All battlefield paths, sockets, tower symbols, enemy shapes, energy cores and
interface decoration are original SVG/CSS artwork stored in the Web source.
No third-party game images, music, sound effects or web fonts are included.
Audio is intentionally omitted; there is no mute control because no sound plays.

The interface uses the device's Segoe UI / Arial / sans-serif font stack.
Screenshots in `docs/screenshots` are captures of this application's real browser
interface. Presentation screenshots use those same captures.
