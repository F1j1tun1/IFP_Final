# Asset credits

Part 1 supplies game data and the standard Blazor application shell. No external
game illustrations, music or sound effects have been imported. Part 2 should use
original vector art or genuinely free assets appropriate to the agreed style.

For every external asset actually included, add its title, creator, exact source
URL, license and any attribution required. Keep a local copy of required license
text. Do not list unused assets as credits and do not assume a search result is free.

assets; keep those original files outside the public repository.
